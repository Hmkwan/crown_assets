📋 概述

本系统支持从 SQLite 迁移到以下数据库:

  • ✅ MySQL/MariaDB - 适用于中小型应用
  • ✅ Microsoft SQL Server - 适用于Windows企业环境
  • ✅ PostgreSQL - 适用于企业级应用

🔄 迁移方式

方式一: 在线导出 (推荐)

优点:

  • ✅ 可视化界面,操作简单
  • ✅ 自动处理数据类型转换
  • ✅ 支持导出到多种数据库格式

使用方法: 数据库管理 → 导出数据

方式二: 命令行

优点:

  • ✅ 适合自动化脚本
  • ✅ 可处理大量数据
  • ✅ 支持定时任务

使用方法: 参见各数据库详细步骤

⚠️ 注意事项:
  • 迁移前请务必备份现有数据库
  • 确保目标数据库服务已启动并可访问
  • 迁移后需要重启应用以使配置生效

🐬 迁移到 MySQL

步骤1: 数据准备

SQLite 自动导出脚本已移除。请准备 PostgreSQL SQL 转储 (.sql) 并在测试环境验证后导入目标数据库，或联系运维获取迁移支持。

步骤2: 创建MySQL数据库
CREATE DATABASE it_asset_db 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
步骤3: 导入数据
mysql -u root -p it_asset_db < migrations/mysql_dump.sql
步骤4: 修改配置文件

编辑 config.py:

SQLALCHEMY_DATABASE_URI = 'mysql+pymysql://用户名:密码@localhost:3306/it_asset_db?charset=utf8mb4'
步骤5: 安装驱动
pip install pymysql cryptography
💡 优化建议
  • 启用慢查询日志监控性能
  • 为常用查询字段创建索引
  • 定期执行 OPTIMIZE TABLE
  • 配置连接池参数

🗄️ 迁移到 SQL Server

步骤1: 导出数据

SQLite 自动导出脚本已移除。请准备 PostgreSQL SQL 转储 (.sql) 并在测试环境验证后导入目标数据库，或联系运维获取迁移支持。

步骤2: 创建数据库
CREATE DATABASE it_asset_db
COLLATE Chinese_PRC_CI_AS;
步骤3: 执行SQL脚本
sqlcmd -S localhost -U sa -P 密码 -d it_asset_db -i migrations/mssql_dump.sql
步骤4: 修改配置文件
SQLALCHEMY_DATABASE_URI = 'mssql+pyodbc://用户名:密码@localhost/it_asset_db?driver=ODBC+Driver+17+for+SQL+Server'
步骤5: 安装ODBC驱动

下载并安装: ODBC Driver 17 for SQL Server

pip install pyodbc
🔧 故障排除

常见问题:

  • 连接失败: 检查TCP/IP协议是否启用 (SQL Server配置管理器)
  • 驱动未找到: 确认ODBC驱动正确安装,版本号与连接字符串匹配
  • 权限错误: 确保SQL Server身份验证已启用

🐘 迁移到 PostgreSQL

步骤1: 导出数据

SQLite 自动导出脚本已移除。请准备 PostgreSQL SQL 转储 (.sql) 并在测试环境验证后导入目标数据库，或联系运维获取迁移支持。

步骤2: 创建数据库
CREATE DATABASE it_asset_db
ENCODING 'UTF8'
LC_COLLATE 'zh_CN.UTF-8'
LC_CTYPE 'zh_CN.UTF-8';
步骤3: 导入数据
psql -U postgres -d it_asset_db -f migrations/pg_dump.sql
步骤4: 修改配置文件
SQLALCHEMY_DATABASE_URI = 'postgresql://用户名:密码@localhost:5432/it_asset_db'
步骤5: 安装驱动
pip install psycopg2-binary
✨ PostgreSQL优势
  • 完全开源,无授权费用
  • 强大的ACID支持和事务处理
  • 支持JSON、数组等高级数据类型
  • 优秀的全文搜索能力
  • 跨平台支持(Windows/Linux/Mac)

⚠️ 常见问题排查
问题1: 字符编码错误 (MySQL)
ALTER DATABASE it_asset_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
问题2: 数据库连接超时
  • ✓ 检查防火墙设置
  • ✓ 确认数据库服务运行中
  • ✓ 验证用户名密码正确
  • ✓ 检查网络连接
问题3: 权限不足错误

MySQL:

GRANT ALL PRIVILEGES ON it_asset_db.* TO '用户名'@'localhost';
FLUSH PRIVILEGES;

PostgreSQL:

GRANT ALL PRIVILEGES ON DATABASE it_asset_db TO 用户名;
