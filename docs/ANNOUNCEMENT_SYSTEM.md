# 系统公告模块使用文档

## 功能概述

系统公告模块允许管理员发布系统维护、功能更新等公告信息,所有用户可在首页和公告列表页查看有效公告。

## 功能特点

### 1. 公告类型
- **普通通知** - 日常通知信息
- **功能更新** - 系统功能更新说明
- **系统维护** - 系统维护通知
- **紧急公告** - 需要紧急关注的信息

### 2. 优先级设置
- 低
- 普通
- 高
- 紧急

### 3. 时间管理
- **发布时间** - 可设置定时发布
- **过期时间** - 可设置公告自动过期
- **创建时间** - 自动记录
- **更新时间** - 自动记录

### 4. 显示控制
- **置顶显示** - 重要公告可置顶
- **发布状态** - 可保存草稿或立即发布
- **富文本编辑** - 支持HTML格式,图文混排

## 使用指南

### 管理员操作

#### 1. 访问公告管理
- 方式1: 首页 → 系统公告 → 公告管理
- 方式2: 直接访问 `/admin/announcements`

#### 2. 创建公告
1. 点击"创建公告"按钮
2. 填写公告信息:
   - **标题** (必填): 公告标题,最多200字符
   - **内容** (必填): 公告正文,支持HTML格式
   - **类型**: 选择公告类型
   - **优先级**: 设置优先级
   - **发布时间**: 留空则立即发布,或设置定时发布
   - **过期时间**: 留空则永不过期
   - **立即发布**: 勾选则发布,不勾选保存为草稿
   - **置顶显示**: 勾选则在列表顶部显示
3. 点击"保存"按钮

#### 3. 编辑公告
1. 在公告管理页面找到要编辑的公告
2. 点击"编辑"按钮
3. 修改信息后点击"保存"

#### 4. 快速操作
- **切换发布状态**: 点击眼睛图标
- **切换置顶状态**: 点击图钉图标
- **删除公告**: 点击删除图标(需确认)

#### 5. 查看统计
公告列表显示以下信息:
- 发布状态(已发布/草稿)
- 生效状态(生效中)
- 发布时间
- 创建者

### 普通用户操作

#### 1. 查看公告
- **首页**: 自动显示最新3条有效公告
- **公告列表**: 访问 `/announcements` 查看所有公告
- **公告详情**: 点击公告标题查看完整内容

#### 2. 公告标识
- **置顶** - 红色"置顶"标签
- **紧急** - 红色"紧急"标签
- **系统** - 黄色"系统"标签
- **更新** - 蓝色"更新"标签

## 数据库结构

### announcements 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 主键 |
| title | String(200) | 公告标题 |
| content | Text | 公告内容 |
| type | String(20) | 公告类型 |
| priority | String(20) | 优先级 |
| is_pinned | Boolean | 是否置顶 |
| is_published | Boolean | 是否发布 |
| publish_time | DateTime | 发布时间 |
| expire_time | DateTime | 过期时间 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| creator_id | Integer | 创建者ID |

### 索引
- `idx_announcements_published` - 发布状态索引
- `idx_announcements_pinned` - 置顶状态索引
- `idx_announcements_type` - 类型索引
- `idx_announcements_publish_time` - 发布时间索引

## 注意事项

1. **权限控制**
   - 只有管理员可以管理公告
   - 所有登录用户可以查看有效公告

2. **公告生效规则**
   - 必须是已发布状态
   - 当前时间 >= 发布时间(如果设置了)
   - 当前时间 < 过期时间(如果设置了)

3. **显示顺序**
   - 置顶公告优先
   - 按优先级排序
   - 按发布时间倒序

4. **富文本编辑**
   - 支持HTML标签
   - 建议使用 Summernote 编辑器
   - 可插入图片、表格、链接等

5. **最佳实践**
   - 重要公告设置置顶
   - 及时维护公告可以设置过期时间
   - 使用合适的公告类型和优先级
   - 内容简洁明了,重点突出

## 常见问题

### Q: 如何让公告在首页显示?
A: 公告必须是已发布且有效状态,系统会自动在首页显示最新3条公告。

### Q: 如何设置定时发布?
A: 在创建/编辑公告时,设置"发布时间"为未来时间,公告会在指定时间后生效。

### Q: 草稿可以被普通用户看到吗?
A: 不可以,只有已发布的公告才对普通用户可见,草稿仅管理员可见。

### Q: 如何批量删除公告?
A: 目前需要逐条删除,建议先筛选需要删除的公告,然后逐一操作。

### Q: 公告内容支持哪些格式?
A: 支持HTML格式,可以使用富文本编辑器编辑,支持文字格式、图片、链接、表格等。
