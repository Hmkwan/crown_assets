## 🎯 快速访问新增功能

### 方法1: 通过管理面板（推荐）

   在管理面板中可以看到两个新增的功能卡片：

   - 功能: 管理9种企业审批流角色

   **🔵 审批流模板** (蓝色边框卡片)

   - 图标: 🗺️ (project-diagram)
   - 描述: "管理审批流程模板和节点"

## 🎓 使用示例

### 为财务人员分配角色

1. 进入 "用户角色管理"
2. 找到财务部门的用户（可使用搜索）
3. 点击 "编辑角色" 按钮
4. 勾选 "财务" 和 "审计/稽核"（财务主管可能需要两个角色）
5. 点击 "保存"
6. 页面显示更新：`财务, 审计/稽核`

### 查看审批流程详情

1. 进入 "审批流模板"
2. 查看 "设备申请流程（企业级8节点）"
3. 可以看到完整的流程：
   - 节点1: 直属主管审批 (department_head)
   - 节点2: IT资产管理员审核 (admin)
   - 节点3: 采购评估与报价 (procurement)
   - 节点4: 金额阈值检查 (condition)
   - 节点5: 财务预算确认 (finance)
   - 节点6: 高层审批 (executive)
   - 节点7: 采购下单与入库 (auto)
   - 节点8: IT分配设备 (admin)

## 💡 提示

1. **首次使用**：所有用户已自动分配默认角色
   - admin 用户 → IT资产管理员
   - department_head 用户 → 部门经理
   - technician 用户 → IT资产管理员
   - 普通用户 → 员工

2. **角色调整**：可随时在管理界面调整用户角色

3. **多角色场景**：小公司中一人多职很常见
   - 财务主管 = 财务 + 审计 + 高层
   - IT经理 = IT资产管理员 + 部门经理
   - 总经理助理 = 高层 + 多个部门经理

4. **搜索技巧**：搜索框支持模糊匹配
   - 输入 "财务" 会过滤出所有财务相关的用户
   - 输入 "admin" 会显示所有管理员
