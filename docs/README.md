## 🎯 如何使用本手册

### 1. 确认您的角色

系统中有以下角色：
- **普通用户**：基本使用权限
- **部门主管**：审批和部门管理权限
- **技术员**：维修和配件管理权限
- **系统管理员**：系统最高权限

### 2. 选择对应手册

根据您的角色，选择相应的操作手册：
- 如果您是普通员工 → 查看《普通员工操作手册》
- 如果您是部门主管 → 查看《部门主管操作手册》
- 如果您是技术员 → 查看《技术员操作手册》
- 如果您是系统管理员 → 查看《系统管理员操作手册》

### 3. 快速查找功能

每个手册都有详细的目录，您可以：
1. 查看目录快速定位所需功能
2. 使用Ctrl+F搜索关键词
3. 参考"常见问题"章节

## 🚀 快速开始

### 新用户入门流程

#### 第一步：登录系统
1. 打开浏览器，输入：`http://内网地址:5020`
2. 输入管理员提供的用户名和密码
3. 首次登录建议修改密码

#### 第二步：熟悉界面
1. 查看首页功能模块
2. 了解顶部导航菜单
3. 查看待处理事项提醒

#### 第三步：学习基本操作
根据您的角色学习：
- **普通员工**：如何申请设备、提交维修工单
- **部门主管**：如何审批申请、管理部门设备
- **技术员**：如何处理维修工单、管理配件
- **系统管理员**：如何管理用户、配置系统
