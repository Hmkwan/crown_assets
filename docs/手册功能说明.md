# 操作手册功能说明

## 功能概述

系统已成功添加在线查看操作手册功能，不同角色的用户可以在导航栏直接访问对应的操作手册。

## 访问方式

### 1. 普通用户、部门主管、技术员

在顶部导航栏右侧可以看到 **📖 操作手册** 链接，点击即可查看自己角色对应的手册。

### 2. 系统管理员

在顶部导航栏右侧的 **⚙️ 系统** 下拉菜单中，可以看到 **📖 操作手册** 选项。

系统管理员可以：
- 查看自己的管理员手册
- 切换查看其他角色的手册（用于指导培训）

## 功能特点

### 1. 角色自动匹配
系统会根据当前登录用户的角色，自动显示对应的操作手册：
- `普通员工` → 显示普通员工操作手册
- `部门主管` → 显示部门主管操作手册
- `技术员` → 显示技术员操作手册
- `系统管理员` → 显示系统管理员操作手册

### 2. 在线阅读
- 美观的排版设计
- 清晰的目录结构
- 支持标题锚点定位
- 响应式布局，适配各种屏幕

### 3. 管理员特权
系统管理员可以查看所有角色的手册，便于：
- 了解各角色的使用方式
- 指导用户使用系统
- 组织培训和学习

### 4. 打印功能
每个手册页面都提供 **🖨️ 打印手册** 按钮，可以：
- 打印为纸质版
- 保存为PDF文件
- 离线查阅

### 5. 便捷导航
- 回到顶部按钮（滚动时自动显示）
- 标题点击复制链接
- 平滑滚动效果
