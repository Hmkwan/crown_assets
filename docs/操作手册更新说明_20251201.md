## 🎯 新功能要点总结

### 1. 审批流程金额阈值配置

**适用角色**：系统管理员

**核心功能**：
- 通过Web界面自定义审批节点的金额阈值
- 设置跳过规则（金额 < 阈值时跳过 / 金额 ≥ 阈值时需要）
- 动态调整审批流程，无需修改代码

**典型应用场景**：
- 配件申请 < 1000元自动审批
- 设备报废 < 1万元免财务审批
- 维修费用 > 3000元需管理员审批

**访问路径**：审批菜单 → 金额阈值配置

---

### 2. 公开仓库功能

**适用角色**：所有用户

**核心功能**：
- 各部门可将闲置设备和配件设为公开
- 其他部门可查看并申请/借用公开资源
- 提高公司整体资源利用率

**用户操作**：
- **普通员工**：查看公开资源，提交借用/申请
- **部门主管**：审批跨部门借用申请
- **技术员**：协助设备交接和检查
- **系统管理员**：设置资源公开状态，管理公开仓库

**访问路径**：首页 → 公开仓库

**主要价值**：
- 💰 减少重复采购
- 🔄 盘活闲置资产
- 🤝 促进部门协作
- ⚡ 快速响应临时需求

---

### 3. 资产标签打印

**适用角色**：系统管理员、技术员

**核心功能**：
- 为设备和配件生成带二维码的资产标签
- 支持单个和批量打印
- 扫码快速查看资产信息

**标签规格**：
- 尺寸：70mm × 70mm
- 分辨率：300 DPI
- 格式：PNG图片

**标签内容**：
- 资产名称、编号
- 二维码（含资产详细信息）
- 所属部门、购买日期、存放位置等

**访问路径**：
- 设备管理 → 选择设备 → 打印标签
- 配件管理 → 选择配件 → 打印标签

**应用场景**：
- 新设备入库
- 资产盘点
- 设备维护记录
- 快速识别资产
