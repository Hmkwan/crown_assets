## 维修工单处理

### 查看待处理工单

**操作路径**：维修工单 → 待处理

#### 工单信息包括：
- 工单编号
- 设备名称和编号
- 故障描述
- 申请人和部门
- 紧急程度
- 提交时间

### 接单处理

#### 步骤1：接受工单
1. 点击工单查看详情
2. 阅读故障描述
3. 查看设备信息
4. 点击"接受工单"按钮
5. 工单状态变更为"进行中"

#### 步骤2：维修处理
1. 到现场检查设备
2. 诊断故障原因
3. 记录处理过程：
   - 故障原因
   - 处理方法
   - 更换配件（如有）

#### 步骤3：配件使用记录
**如需更换配件**：
1. 点击"添加配件"
2. 选择使用的配件
3. 输入使用数量
4. 系统自动扣减库存

#### 步骤4：完成工单
1. 点击"完成维修"按钮
2. 填写维修总结：
   - 故障原因
   - 处理方法
   - 建议措施
   - 维修费用（如有）
3. 上传维修后照片（可选）
4. 提交完成

### 工单管理

**操作路径**：维修工单

#### 工单视图：
- **待处理**：未接单的工单
- **进行中**：正在处理的工单
- **已完成**：完成的工单
- **全部工单**：所有工单记录

### 紧急工单处理

**特点**：
- 🚨 红色标记
- 优先显示
- 需24小时内响应

**处理流程**：
1. 优先接单
2. 快速诊断
3. 及时反馈
4. 尽快完成

## 配件管理

### 查看配件库存

**操作路径**：配件管理 → 配件列表

#### 库存信息：
- 配件名称、编号
- 配件类型
- 当前库存数量
- 最低库存预警
- 单价
- 存放位置

### 配件入库

**操作路径**：配件管理 → 添加配件

#### 步骤：
1. 点击"添加配件"
2. 填写配件信息：
   - 配件名称
   - 配件编号
   - 配件类型
   - 数量
   - 单价
   - 存放位置
   - 入库日期
3. 提交保存

### 配件出库（维修使用）

**方式1：通过工单**
- 处理维修工单时添加配件
- 系统自动扣减库存

**方式2：手动出库**
**操作路径**：配件管理 → 选择配件 → 出库

适用于：
- 配件领用
- 批量更换
- 设备组装

### 库存预警

**操作路径**：配件管理 → 库存预警

#### 预警类型：
- 🔴 **低库存**：库存低于最低库存
- 🟡 **即将不足**：库存接近最低值
- 🔵 **充足**：库存正常

#### 处理方式：
1. 查看预警配件
2. 评估采购需求
3. 提交配件申请给管理员
4. 跟踪采购进度

### 配件盘点

**操作路径**：配件管理 → 库存盘点

**建议**：每月进行一次盘点

#### 步骤：
1. 核对实物数量
2. 更新系统库存
3. 记录盘点差异
4. 分析差异原因

## 资产标签打印（新功能）

### 功能概述

**操作路径**：设备管理 → 设备详情 → 打印标签 或 配件管理 → 配件详情 → 打印标签

为设备和配件生成带二维码的资产标签，便于资产管理和快速识别。

### 打印设备标签

**操作路径**：设备管理 → 选择设备 → 操作 → 打印标签

#### 步骤：
1. 在设备列表中找到目标设备
2. 点击"打印标签"按钮
3. 系统自动生成标签预览
4. 核对标签信息（设备名称、编号、二维码等）
5. 点击浏览器打印功能打印

#### 标签内容：
- 设备名称
- 设备编号
- 设备二维码（扫码可查看详情）
- 所属部门
- 购买日期
- 存放位置

### 打印配件标签

**操作路径**：配件管理 → 选择配件 → 操作 → 打印标签

操作步骤与设备标签相同。

#### 标签内容：
- 配件名称
- 配件编号
- 配件二维码
- 所属部门
- 存放位置
- 规格型号

### 批量打印标签

**适用场景**：新设备入库、配件整理、资产盘点

#### 操作：
1. 在设备或配件列表中勾选多个项目
2. 点击"批量打印标签"按钮
3. 系统生成所有标签
4. 批量打印

### 标签使用建议

#### 标签粘贴位置：
- **设备**：设备正面或侧面明显位置
- **配件**：配件包装盒或本体
- **避免**：易磨损、高温、潮湿位置

#### 标签维护：
- 定期检查标签完整性
- 发现损坏及时重新打印
- 设备调拨后更新标签信息
- 记录标签更换历史

#### 扫码应用：
- 使用手机扫描二维码快速查看资产信息
- 盘点时扫码核对
- 维修时扫码记录
- 借用归还时扫码确认

### 标签规格

- **尺寸**：70mm × 70mm
- **分辨率**：300 DPI
- **格式**：PNG图片
- **打印机**：普通标签打印机或A4纸裁剪
