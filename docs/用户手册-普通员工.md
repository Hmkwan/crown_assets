- 📝 设备申请

- 🔧 维修工单提交

- 🔔 通知查看

## 设备申请

### 申请新设备

**操作路径**：首页 → 设备申请

#### 步骤：
1. 点击首页的"设备申请"卡片
2. 点击"申请新设备"按钮
3. 填写申请表单：
   - **设备类型**：选择所需设备类型（如台式电脑、笔记本等）
   - **品牌**：填写品牌要求（可选）
   - **型号**：填写型号要求（可选）
   - **申请原因**：详细说明申请理由
   - **预计使用时间**：选择开始使用日期
4. 点击"提交申请"

#### 审批流程：
```
员工提交 → 部门主管审批 → 管理员审批 → 完成
```

### 查看申请状态
**操作路径**：设备申请 → 我的申请

可以查看：
- ✅ 已批准
- ⏳ 审批中
- ❌ 已拒绝
- 📝 草稿

## 设备借用

### 借用设备

**操作路径**：首页 → 设备借用申请

#### 步骤：
1. 点击"发起借用申请"
2. 填写借用信息：
   - **选择设备**：从可借用设备列表中选择
   - **借用理由**：说明借用原因
   - **预计归还日期**：选择归还时间
3. 提交申请

#### 借用状态：
- **审批中**：等待部门主管/管理员审批
- **已批准**：可以领取设备
- **使用中**：正在借用
- **已归还**：已完成归还

### 归还设备

**操作路径**：设备借用申请 → 我的借用 → 归还

1. 找到借用记录
2. 点击"归还设备"按钮
3. 确认归还信息
4. 提交归还

**注意**：请按时归还，逾期可能影响后续借用权限

## 维修工单

### 提交维修工单

**操作路径**：首页 → 提交维修工单

#### 步骤：
1. 点击"创建维修工单"
2. 填写工单信息：
   - **选择设备**：从您部门的设备中选择故障设备
   - **故障描述**：详细描述故障现象
   - **紧急程度**：选择紧急、普通、低
3. 上传图片（可选）：故障设备照片
4. 点击"提交工单"

#### 工单状态：
- **已提交**：等待审批
- **进行中**：技术员正在维修
- **已完成**：维修完成
- **已取消**：工单已取消

### 查看工单进度

**操作路径**：维修工单 → 我的工单

可以：
- 查看工单详情
- 查看维修进度
- 添加备注说明
- 查看维修结果

## 公开仓库（新功能）

### 功能概述

**操作路径**：首页 → 公开仓库

公开仓库展示各部门共享的闲置设备和配件，您可以查看并借用/申请这些资源。

### 查看公开资源

#### 访问方式：
1. 点击首页"公开仓库"卡片
2. 或通过顶部菜单 → 公开仓库

#### 可以查看：
**公开设备**：
- 设备名称、编号
- 设备类型和品牌
- 所属部门
- 设备状态
- 借用按钮

**公开配件**：
- 配件名称、编号
- 配件类型
- 库存数量
- 所属部门
- 申请按钮

### 借用公开设备

**操作路径**：公开仓库 → 公开设备 → 选择设备 → 借用

#### 步骤：
1. 在公开仓库中浏览设备
2. 找到需要的设备，点击"借用"按钮
3. 填写借用信息：
   - 借用理由（必填）
   - 借用期限（选择归还日期）
4. 提交借用申请
5. 等待设备所属部门主管审批

#### 审批流程：
```
员工提交借用申请 → 设备所属部门主管审批 → 借用成功
```

**注意事项**：
- 跨部门借用需要对方部门主管批准
- 按时归还设备
- 保持设备完好
- 归还时需验收

### 申请公开配件

**操作路径**：公开仓库 → 公开配件 → 选择配件 → 申请

#### 步骤：
1. 切换到"公开配件"标签
2. 浏览配件列表
3. 找到需要的配件，点击"申请"按钮
4. 填写申请信息：
   - 申请数量
   - 使用用途
5. 提交申请
6. 按正常审批流程等待批准

### 公开仓库搜索和筛选

#### 搜索功能：
- 在搜索框输入关键词搜索设备/配件名称
- 支持模糊搜索

#### 筛选功能：
- 按部门筛选：查看特定部门的公开资源
- 切换设备/配件：点击对应Tab查看不同类型资源

### 公开仓库的好处

**对您的好处**：
- 🔍 快速找到所需资源
- 💰 无需等待新采购
- 🤝 部门间资源共享
- ⚡ 临时需求快速解决

**使用提示**：
- 优先查看公开仓库，避免重复申请
- 临时需求可借用而不是申请采购
- 爱惜借用的设备和配件
- 按时归还，方便他人使用

## 常见问题

### Q1: 忘记密码怎么办？
**A**: 请联系信息部管理员重置密码，或使用"忘记密码"功能。

### Q2: 申请设备需要多久？
**A**: 一般审批流程需要1-3个工作日，紧急情况可联系部门主管加急处理。

### Q3: 设备故障如何快速处理？
**A**: 提交维修工单时选择"紧急"级别，技术员会优先处理。

### Q4: 可以借用其他部门的设备吗？
**A**: 可以！请访问公开仓库，查看其他部门公开的设备，提交借用申请即可。

### Q5: 配件申请被拒绝怎么办？
**A**: 查看拒绝原因，修改申请内容后重新提交，或联系审批人沟通。

### Q6: 如何查看我的设备清单？
**A**: 进入"设备管理"页面，系统会显示分配给您的所有设备。

### Q7: 设备需要定期维护吗？
**A**: 是的，系统会自动提醒设备维护时间，请及时提交维护工单。

### Q8: 公开仓库中的设备可以直接拿走吗？
**A**: 不可以。需要提交借用申请，等待对方部门主管批准后才能借用。

### Q9: 如何知道有哪些公开资源可用？
**A**: 定期查看公开仓库，系统会展示所有部门公开的设备和配件。
