## 用户管理

### 用户列表

**操作路径**：管理后台 → 用户管理

#### 功能：
- 查看所有用户
- 搜索和筛选用户
- 查看用户详细信息
- 管理用户状态

### 添加新用户

**操作路径**：用户管理 → 添加用户

#### 步骤：
1. 点击"添加用户"按钮
2. 填写用户信息：
   - **用户名**（必填，用于登录）
   - **密码**（必填，首次登录密码）
   - **姓名**（必填）
   - **工号**（可选）
   - **邮箱**（可选）
   - **电话**（可选）
   - **部门**（必选）
3. 提交保存

**注意**：
- 用户名必须唯一
- 建议使用工号作为用户名
- 初始密码建议用户首次登录修改

### 编辑用户信息

**操作路径**：用户管理 → 选择用户 → 编辑

可修改：
- 基本信息（姓名、邮箱、电话）
- 所属部门
- 用户状态

**不可修改**：
- 用户名（系统唯一标识）

### 重置用户密码

**操作路径**：用户管理 → 选择用户 → 重置密码

#### 使用场景：
- 用户忘记密码
- 密码安全问题
- 新员工入职

#### 步骤：
1. 选择需要重置密码的用户
2. 点击"重置密码"
3. 设置新密码或使用系统默认密码
4. 通知用户新密码

### 用户角色管理

**操作路径**：管理后台 → 用户角色管理

#### 系统角色：
1. **普通用户**
   - 基本使用权限
   - 申请设备、借用、维修等

2. **部门主管**
   - 审批部门员工申请
   - 管理部门设备和人员
   - 查看部门报表

3. **技术员**
   - 处理维修工单
   - 管理配件
   - 设备维护

4. **系统管理员**
   - 系统最高权限
   - 全局管理和配置

#### 工作流角色（可多选）：
- **部门主管**：审批部门申请
- **IT部门主管**：审批IT相关申请
- **财务**：审批涉及费用的申请
- **采购**：采购相关审批

### 设置用户角色

**操作路径**：用户角色管理 → 选择用户 → 设置角色

#### 步骤：
1. 选择用户
2. 勾选相应角色
3. 保存设置

**注意**：
- 角色变更立即生效
- 用户可同时拥有多个工作流角色
- 系统角色只能选一个

### 停用/启用用户

**操作路径**：用户管理 → 选择用户 → 停用/启用

#### 停用场景：
- 员工离职
- 长期休假
- 违规使用

**注意**：停用后用户无法登录系统

### ⭐ 审批流程金额阈值配置（新功能）

**操作路径**：审批菜单 → 金额阈值配置

**功能说明**：无需修改代码，通过Web界面自定义审批流程节点的金额阈值和跳过规则

#### 主要功能：

**1. 查看流程配置**
- 从下拉菜单选择工单类型（维修工单、配件申请、设备调拨等）
- 显示该类型的所有审批节点
- 查看每个节点的序号、名称、角色、金额阈值、跳过规则

**2. 编辑节点配置**

点击"编辑"按钮可修改：
- **节点名称**：如"管理员审批"、"财务审核"
- **所需角色**：部门负责人、管理员、技术员、仓库管理员、财务
- **执行序号**：节点在流程中的执行顺序
- **金额阈值**：设置触发金额（单位：元）
- **跳过规则**：
  - 金额 < 阈值时跳过：低于阈值时自动跳过该节点
  - 金额 ≥ 阈值时需要：达到阈值时才需要该节点

**3. 添加新节点**
1. 点击"添加新节点"按钮
2. 填写节点名称
3. 选择所需角色
4. 设置执行序号
5. （可选）设置金额阈值和跳过规则
6. 点击"添加"保存

**4. 删除节点**

点击"删除"按钮移除不需要的审批节点（软删除，可恢复）

#### 使用场景示例：

**场景1：配件申请自动审批**
- 需求：配件金额小于1000元时，无需管理员审批
- 配置：节点"管理员审批"，金额阈值1000.00，规则"金额 < 阈值时跳过"
- 效果：
  - 申请金额 ¥500 → 跳过管理员审批
  - 申请金额 ¥1500 → 需要管理员审批

**场景2：设备报废财务把关**
- 需求：设备价值小于1万元时，无需财务审批
- 配置：节点"财务审批"，金额阈值10000.00，规则"金额 < 阈值时跳过"
- 效果：自动筛选高价值设备报废需财务审批

**场景3：维修成本控制**
- 需求：维修费用超过3000元时，需要管理员额外审批
- 配置：节点"管理员审批"，金额阈值3000.00，规则"金额 ≥ 阈值时需要"
- 效果：高成本维修增加额外审批环节

#### 注意事项：
- ✅ 修改后立即生效，影响新提交的工单
- ⚠️ 不影响进行中的审批流程
- 🔒 只有管理员可以修改流程配置
- 💾 建议定期备份配置

## 公开仓库管理（新功能）

### 功能概述

**操作路径**：首页 → 公开仓库 或 管理后台 → 公开仓库

公开仓库功能允许各部门将闲置设备和配件设置为公开状态，供其他部门查看和申请，提高资源利用率。

### 查看公开仓库

**操作路径**：公开仓库

#### 功能：
- 查看所有部门公开的设备和配件
- 按部门筛选
- 关键词搜索
- 切换设备/配件视图
- 统计公开资源数量

#### 显示内容：
**公开设备**：
- 设备名称
- 设备编号
- 设备类型
- 品牌型号
- 所属部门
- 设备状态
- 借用按钮

**公开配件**：
- 配件名称
- 配件编号
- 配件类型
- 库存数量
- 单价
- 所属部门
- 申请按钮

### 设置配件公开状态

**操作路径**：配件管理 → 配件列表

**权限**：仅管理员可操作

#### 单个配件操作：
1. 在配件列表中找到目标配件
2. 查看"公开状态"列（显示公开/私有徽章）
3. 点击"公开"或"取消公开"按钮
4. 确认操作

#### 批量操作：
1. 勾选多个配件
2. 点击"批量公开"或"批量取消公开"按钮
3. 确认批量操作

### 设置设备公开状态

**操作路径**：设备管理 → 设备列表

**权限**：仅管理员可操作

操作方式与配件类似，可单个或批量设置设备的公开状态。

### 公开仓库管理建议

**适合公开的资源**：
- ✅ 闲置设备
- ✅ 过剩配件
- ✅ 可共享资源
- ✅ 通用设备/配件

**不适合公开的资源**：
- ❌ 正在使用的设备
- ❌ 部门专用设备
- ❌ 库存不足的配件
- ❌ 高价值敏感设备

**最佳实践**：
1. 定期清理和更新公开仓库
2. 确保公开资源信息准确
3. 及时处理跨部门申请
4. 建立公开资源借用规范

## 资产标签打印（新功能）

### 功能概述

**操作路径**：设备管理 → 设备详情 → 打印标签 或 配件管理 → 配件详情 → 打印标签

系统支持为设备和配件生成带二维码的资产标签，用于资产管理和快速识别。

### 标签规格

- **尺寸**：70mm × 70mm
- **分辨率**：300 DPI
- **格式**：PNG图片
- **内容**：
  - 资产名称
  - 资产编号
  - 二维码（含资产信息）
  - 部门信息
  - 购买日期
  - 存放位置

### 打印设备标签

**操作路径**：设备管理 → 选择设备 → 操作 → 打印标签

#### 步骤：
1. 在设备列表中找到目标设备
2. 点击"打印标签"按钮
3. 系统生成标签预览
4. 核对标签信息
5. 点击"打印"按钮打印

**或者批量打印**：
1. 勾选多个设备
2. 点击"批量打印标签"
3. 系统生成所有标签
4. 批量打印

### 打印配件标签

**操作路径**：配件管理 → 选择配件 → 操作 → 打印标签

操作步骤与设备标签相同。

### 标签内容说明

**设备标签包含**：
- 设备名称
- 设备编号（唯一标识）
- 设备二维码（扫码查看详情）
- 所属部门
- 购买日期
- 存放位置
- 公司标识

**配件标签包含**：
- 配件名称
- 配件编号
- 配件二维码
- 所属部门
- 存放位置
- 规格型号

### 标签使用建议

**标签粘贴位置**：
- 设备：明显可见位置（如设备正面、侧面）
- 配件：包装盒或配件本体

**标签维护**：
- 定期检查标签完整性
- 损坏标签及时重新打印
- 设备调拨后更新标签信息

**扫码管理**：
- 使用手机扫描二维码可快速查看资产信息
- 方便盘点和资产核查
- 提高资产管理效率

## 常见问题

### Q1: 如何批量创建用户？
**A**: 使用用户导入功能，下载模板填写后批量导入。

### Q2: 忘记超级管理员密码怎么办？
**A**: 联系系统开发人员通过数据库重置。

### Q3: 如何修改工作流程？
**A**: 进入工作流配置，选择对应类型修改节点和规则。

### Q4: 数据库备份存储在哪里？
**A**: 默认存储在服务器的backups目录，建议定期下载到本地。

### Q5: 如何查看某个用户的所有操作记录？
**A**: 在系统日志中按用户名筛选操作日志。

### Q6: 设备编号重复怎么办？
**A**: 检查编号规则，修改重复编号或使用系统自动生成。

### Q7: 如何设置审批超时自动提醒？
**A**: 在系统设置→审批设置中配置超时时间和提醒方式。
