## 审批管理

### 审批中心

**操作路径**：首页 → 我的审批 或 顶部菜单 → 审批

#### 待审批事项包括：
1. **设备申请**：员工申请新设备
2. **设备借用**：员工借用设备申请
3. **维修工单**：设备维修申请
4. **配件申请**：配件领用申请
5. **设备调拨**：设备部门间调拨
6. **设备报废**：设备报废申请

### 审批操作流程

#### 1. 查看待审批列表
**操作路径**：我的审批 → 待审批

可以看到：
- 申请人
- 申请类型
- 申请时间
- 紧急程度

#### 2. 审批操作步骤
1. 点击申请查看详情
2. 仔细阅读申请内容：
   - 申请理由
   - 申请明细
   - 附件资料
3. 做出决策：
   - **批准**：点击"批准"按钮，填写审批意见（可选）
   - **拒绝**：点击"拒绝"按钮，**必须填写拒绝理由**
4. 提交审批结果

#### 3. 批量审批
**操作路径**：我的审批 → 勾选多个申请 → 批量批准/拒绝

**注意**：
- 批量操作前请仔细核对每个申请
- 重要申请建议单独审批

### 审批时效要求
- ⚡ **紧急申请**：24小时内处理
- 📋 **普通申请**：2个工作日内处理
- 📌 **低优先级**：3个工作日内处理

### 审批记录查询
**操作路径**：我的审批 → 审批记录

可以查看：
- 已批准的申请
- 已拒绝的申请
- 审批时间和意见

## 部门设备管理

### 查看部门设备清单

**操作路径**：设备管理 → 部门设备

#### 设备信息包括：
- 设备名称、编号
- 设备类型、品牌、型号
- 使用状态（正常/维修中/已借出）
- 使用人员
- 设备位置

### 设备分配

**操作路径**：设备管理 → 选择设备 → 分配给员工

#### 步骤：
1. 选择可用设备
2. 点击"分配"按钮
3. 选择员工
4. 填写分配说明
5. 确认分配

### 设备回收

**操作路径**：设备管理 → 选择设备 → 回收

用于：
- 员工离职设备回收
- 设备更换
- 设备调拨前准备

### 设备调拨申请

**操作路径**：设备管理 → 发起调拨

#### 使用场景：
- 部门间设备调配
- 员工转岗设备转移
- 设备集中管理

#### 步骤：
1. 选择要调拨的设备
2. 选择目标部门
3. 填写调拨理由
4. 提交审批（需管理员批准）

## 常见问题

### Q1: 如何快速处理大量审批？
**A**: 使用批量审批功能，但重要申请建议单独审批并仔细核查。

### Q2: 员工申请被我拒绝后还能再申请吗？
**A**: 可以，员工可以修改申请内容后重新提交。

### Q3: 如何查看某个员工的所有设备？
**A**: 进入"用户管理" → "部门人员" → 点击员工姓名查看详情。

### Q4: 部门设备不够用怎么办？
**A**: 可以查看公开仓库借用其他部门闲置设备，或提交设备采购申请。

### Q5: 审批超时会有什么影响？
**A**: 系统会发送提醒通知，长期超时可能影响员工工作效率。

### Q6: 如何处理紧急审批？
**A**: 紧急申请会在审批列表中标注，请优先处理并尽快做出决策。

### Q7: 可以撤回已批准的审批吗？
**A**: 已批准的审批无法直接撤回，请联系管理员处理。

### Q8: 如何查看本部门公开的资源被谁借用了？
**A**: 在我的审批中查看借用审批记录，或在设备管理中查看设备状态。

### Q9: 公开仓库中的资源可以直接借用吗？
**A**: 不可以直接借用，需要提交借用申请，等待资源所属部门主管审批。

## 审批注意事项

### ✅ 批准前检查
1. 申请理由是否充分
2. 申请内容是否合理
3. 是否符合部门预算
4. 是否有替代方案

### ❌ 拒绝时说明
1. 必须填写明确的拒绝理由
2. 提供改进建议（如适用）
3. 说明是否可重新申请

### 📝 审批建议
1. 保持客观公正
2. 考虑部门整体利益
3. 合理控制成本
4. 提高审批效率
