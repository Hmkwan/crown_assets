## 📚 功能使用说明

### 1️⃣ 成本分析

**应用场景**：
- 追踪资产总成本（采购+维护+升级）
- 评估投资回报率（ROI）
- 分析维护成本趋势

**使用流程**：
1. 进入 `/reports/cost-analysis` 查看所有资产的成本概览
2. 点击某个资产进入 `/asset/<id>/cost` 查看详细成本分析
3. 点击"编辑成本"进入表单，更新：
   - 采购价格
   - 年折旧率
   - 年均维护成本
   - 历史升级费用
4. 系统自动计算：
   - 当前净值 = 采购价 - (折旧 × 使用年数)
   - ROI = (当前值 - 总成本) / 采购价 × 100%

**关键字段说明**：

```
年折旧率(%)      推荐值
─────────────────────
电脑/笔记本      18-20%
服务器           10-15%
打印机/扫描仪    20-25%
网络设备         12-15%
其他设备         15%
```

---

### 2️⃣ 库存预警

**应用场景**：
- 防止关键配件缺货
- 优化采购成本
- 避免过度库存

**预警等级**：

```
🚨 紧急(Critical)  库存 < 紧急阈值
   └─ 立即采购，可能影响业务
   
⚠️ 预警(Warning)   库存 < 最小阈值
   └─ 建议本月内采购
   
✓ 正常(Normal)     库存在合理范围内
   └─ 可灵活安排采购
```

**使用流程**：
1. 进入 `/inventory/warnings` 查看库存状况
2. 点击配件的"配置"按钮，设置预警阈值：
   - 紧急阈值：低于此数量需立即采购 (通常为2-3)
   - 最小阈值：低于此数量需计划采购 (通常为5-10)
   - 最大阈值：库存上限，超过此数量为过剩 (通常为50-100)
3. 进入 `/inventory/procurement-plan` 查看自动生成的采购建议
4. 建议优先采购 🚨**紧急** 和 ⚠️**预警** 等级的配件

**配件预警规则示例**：

```json
{
  "配件名称": "8G内存条",
  "当前库存": 3,
  "紧急阈值": 2,
  "最小阈值": 5,
  "最大阈值": 100,
  "建议采购量": 50,
  "预警状态": "预警 ⚠️"
}
```

### 3️⃣ 生命周期管理

**应用场景**：
- 完整追踪资产的全生命周期
- 判断资产何时应该报废
- 评估资产整体健康度

**生命周期事件类型**：

```
📦 采购     - 资产购买时记录（采购价格）
📍 部署     - 资产调拨到不同部门时记录
🔧 维护     - 每次维修/保养时记录（维护费用）
⬆️ 升级     - 资产升级/改造时记录（升级费用）
🗑️ 报废     - 资产淘汰/报废时记录
```

**使用流程**：

1. **查看生命周期**：进入 `/asset/<id>/lifecycle`
   - 查看时间线上的所有事件
   - 了解资产的完整使用历史
   - 查看成本累计

2. **添加生命周期事件**：点击"➕ 记录生命周期事件"
   - 选择事件类型
   - 输入事件日期和描述
   - 如果是维护/升级/采购，输入费用
   - 保存

3. **报废评分**：进入 `/asset/lifecycle/retirement-analysis`
   - 系统自动评分，最高100分
   - 得分 > 70分：建议报废 🚨
   - 得分 50-70分：计划更新 ⚠️
   - 得分 < 50分：继续使用 ✓

**报废评分算法**：

```
使用年限         ≥5年 → +30分
维护成本占比     ≥50% → +25分
年均维修次数     >5次 → +20分
残值率           <10% → +15分
技术落后         停产  → +10分
                ───────────
                总分 = 上述加总

评级：
71-100分 → 高风险  🚨 立即报废
51-70分  → 中风险  ⚠️ 计划更新
31-50分  → 中低风险 ⓘ  监控维护
0-30分   → 低风险  ✓  继续使用
```

## 🔧 配置说明

### 成本参数

在编辑资产成本时配置：

```
采购价格          ← 资产购买时的价格
年折旧率(%)       ← 采用直线折旧法
预期使用年限(年)  ← 计划使用多少年
残值率(%)         ← 报废时的回收价值百分比
年均维护成本      ← 平均每年的维护支出
```

**计算公式**：

```
年折旧额 = 采购价格 × 年折旧率 ÷ 100
累计折旧 = 年折旧额 × 使用年数
当前净值 = 采购价格 - 累计折旧
生命周期总成本 = 采购价格 + 维护成本 + 升级成本 + 其他费用
```

### 库存预警规则

在库存预警配置中设置：

```
最小阈值        → 触发"预警"的库存数量
紧急阈值        → 触发"紧急"的库存数量
最大阈值        → 库存不应超过的数量
推荐采购数量    → 系统建议的补货数量
```

## 🐛 故障排除

### 常见问题

**Q1: 初始化时显示"表已存在"**
```
A: 这是正常的，SQLAlchemy自动跳过已存在的表
```

**Q2: 生命周期页面显示为空**
```
A: 需要手动添加生命周期事件，初始化时不会添加历史数据
```

**Q3: 成本计算结果不对**
```
A: 检查是否正确配置了年折旧率和预期使用年限
```

**Q4: 库存预警一直不更新**
```
A: 手动点击"🔄 检查预警"按钮，或等待定时任务（将在Phase 2中实现）
```
